# YouTube thumbnail: 7+ shot rallies (team singles, Cincy Open courts)

Three 1280x720 candidates generated from the court photos in `src/`.
Upload the `.jpg` versions (all well under YouTube's 2 MB limit).

| File | Concept |
|---|---|
| `out/A-action.jpg` | Full-bleed forehand shot, big title bottom-left, team selfie inset top-right |
| `out/B-squad.jpg` | Team selfie as the hero (faces drive clicks), title stacked at the bottom |
| `out/C-split.jpg` | Dusk stadium column with a giant "7+" on the left, forehand action on the right |

Regenerate after editing text, fonts or crops:

```
pip install pillow
python3 make_thumbnails.py
```

Fonts: Anton and Bebas Neue (SIL Open Font License, from Google Fonts).
